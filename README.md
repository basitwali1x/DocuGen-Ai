# DocuGen-Ai: YouTube Creator

DocuGen-AI is a high-end, long-form YouTube documentary engine (10-15 mins) designed to transform simple topics into immersive cinematic experiences.

## 🎞️ Key Features
- **Viral Scripting Engine**: Powered by **Gemini 3.1 Pro** to generate deep, 6-chapter narrative arcs with high-engagement hooks.
- **Cinematic Visuals**: Uses **Gemini 2.5 Flash Image** to generate custom 16:9 cinematic B-roll for every scene (48 micro-scenes).
- **Professional Narration**: Integrated with **Gemini 3.1 Flash TTS** for realistic, theme-appropriate voiceovers.
- **Advanced Editing**: Featuring kinetic typography, Ken Burns effects, and automatic background music syncing.
- **MP4 Export**: Built-in 'Download MP4' functionality for direct YouTube uploads.

## 🛠️ Tech Stack
- **AI Models**: Gemini 3.1 Pro, Gemini 2.5 Flash, Gemini 3.1 Flash TTS.
- **Frontend**: React, Tailwind CSS, Framer Motion.
- **Resilience**: Optimized with exponential backoff and 3-second throttling for quota stability.

## 🚀 Current Status
The project is currently optimized for long-form content (15-minute runtime) with a 48-scene structure.
